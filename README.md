# 📱 Campus Attend – QR Attendance System

**A Smart, Simple, and Digital Attendance Management System**

Campus Attend is a web-based attendance management system designed to simplify student attendance tracking using QR codes. It aims to reduce manual work, save time, and make attendance management easier through a user-friendly interface.

## 🎯 About the Project

Traditional attendance systems often require manual entry, which can consume time and lead to errors. Campus Attend aims to make this process easier through digital attendance management and QR code technology.

The project is developed using React.js and Vite, with a responsive interface designed for desktop and mobile devices.

## 🎯 Objectives

- Digitize the attendance management process.
- Reduce manual attendance entry.
- Simplify attendance tracking using QR codes.
- Improve the accuracy and accessibility of attendance records.
- Provide a simple and mobile-friendly user interface.

## ⚙️ Installation and Setup

### Prerequisites

Install the following before running the project:

- [Node.js](https://nodejs.org/)
- [Visual Studio Code](https://code.visualstudio.com/)
- [Git](https://git-scm.com/)

### Step 1: Clone the Repository

Replace `YOUR_USERNAME` with your GitHub username.

```bash
git clone https://github.com/YOUR_USERNAME/CAMPUS-ATTEND.git
```

### Step 2: Open the Project Folder

```bash
cd "CAMPUS ATTEND"
```

If the cloned folder has a different name, use that folder name instead.

### Step 3: Install Dependencies

```bash
npm install
```

### Step 4: Start the Development Server

```bash
npm run dev
```

### Step 5: Open the Website

Open the local URL displayed in the terminal. For example:

```text
http://localhost:3000
```

The actual port may differ depending on your Vite configuration.

## 📱 Mobile Access

Campus Attend is designed to support access from mobile devices through a web browser.

To access the development version from a mobile phone:

1. Connect the laptop and mobile phone to the same Wi-Fi network.
2. Start the development server with:

   ```bash
   npm run dev -- --host 0.0.0.0
   ```

3. Find the network URL or laptop IP address and port displayed by the development server.
4. Open that URL in the mobile browser.

For home-screen installation with a custom app icon, the project needs a valid PWA manifest, appropriate icon images, and a suitable secure hosting setup.

## 🔨 Build for Production
